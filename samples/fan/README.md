# samples/fan/ · 泛音采样层(现处休眠)

放置 `N.wav|m4a|mp3`(N=1..7,N 弦七徽泛音,标准音 A440 正调)即自动生效:
引擎去首部静音、峰值归一、按徽位倍频移调;缺文件的弦回退合成泛音。

## 2026-08 首次尝试的结论(v0.21.1 入库,v0.21.2 退役)

用户自录七徽泛音实测后判定:**合成泛音(KS+空气琴参数)才是本产品的声音**
——"玉磬和骨风铃"。真采样的三个不可修问题:

1. 噪底:录音峰值仅 0.12,归一化把房间底噪抬高 ~18dB;
2. 起振迟滞:泛音自然软起几十毫秒,噪底又让去静音裁不掉,体感"反应一下才出音";
3. 移调走律:变速播放连噪底与房间共振一起变调,律感涣散。

若将来重试,需要:近距离收音、安静房间、峰值 ≥ -6dBFS、逐弦单独成条;
但更可能的结论是:空气之琴的美学本就属于合成之声,此层保持休眠即可。
